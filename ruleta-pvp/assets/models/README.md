# Biblioteca de modelos (ruleta-pvp)

Acá se dejan los modelos 3D reales (.rbxm / .rbxmx) que reemplazan a las piezas primitivas del lobby.
Rojo convierte esta carpeta en `ServerStorage.ModelLibrary`. El nombre del archivo (sin extensión) es el nombre de la ranura.

Si la carpeta solo tiene este README, el juego se arma igual que siempre con las piezas en código.

Guía completa, con la tabla de ranuras, tamaños y qué buscar en el Creator Store: `docs/modelos/ruleta-pvp.md`.

Resumen rápido: Toolbox > insertar > revisar que no tenga scripts > click derecho > Save to File (.rbxm) > guardar acá como `<ranura>.rbxm` (ej. `pylon.rbxm`, variantes `pylon_1.rbxm`, `pylon_2.rbxm`) > `rojo build`.
